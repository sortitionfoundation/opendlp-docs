Running a selection is a [key stage of the democratic lottery](/democratic-lottery/selection/algorithms/).

In this section we discuss:

- What respondent data should look like and how to work with it.
- What target data should look like and how to work with it.
- How to test whether our targets are coherent and feasible.
- How to set the selection algorithm running.
- How to understand output, including error messages.
